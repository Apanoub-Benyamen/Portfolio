## المشاريع المميزة

### 01. تحليل سلوك العملاء الشرائي | مشروع تحليلي متكامل

**Python · PostgreSQL · SQL · Power BI**

تحليل 3,900 سجل لعمليات شراء العملاء، بهدف فهم أنماط السلوك الشرائي، وتقسيم العملاء إلى شرائح، ودراسة الاشتراكات، وتحديد فرص تحسين الإيرادات.

**أبرز النتائج:**

- تحليل إيرادات مسجلة بقيمة **233,081 دولارًا** من خلال 3,900 عملية شراء.
- تنفيذ عمليات تجهيز وتنظيف البيانات، والتحليل الاستكشافي، والتحليل باستخدام SQL.
- تطوير لوحة معلومات تفاعلية باستخدام Power BI لعرض المؤشرات والرؤى التجارية.
- دراسة أنماط الشراء لدعم استراتيجيات الاحتفاظ بالعملاء وتحسين القرارات التسويقية.

[عرض دراسة الحالة](https://apanoub-benyamen.github.io/Portfolio/projects/customer-behavior.html) | [عرض العرض التقديمي](dist/assets/customer-shopping-presentation.pdf)

### 02. اكتشاف الجرائم المالية ومكافحة غسل الأموال

**Python · Machine Learning · Financial Analytics**

دراسة أنماط المعاملات المالية والتحديات المرتبطة باكتشاف الأنشطة المشبوهة داخل مجموعات البيانات التي تعاني من اختلال شديد في توزيع الفئات.

**أبرز النتائج:**

- دراسة ما يقارب **9.5 مليون معاملة مالية**.
- تحليل مجموعة بيانات لا تتجاوز فيها نسبة الحالات الإيجابية **0.104% تقريبًا**.
- استكشاف أساليب اكتشاف الحالات النادرة، والتعامل مع عدم توازن الفئات، وتقييم أداء النماذج.
- دراسة مخاطر تسرب البيانات وأهمية التقييم الدقيق للنماذج المستخدمة في التحليل المالي.

[عرض دراسة الحالة](https://apanoub-benyamen.github.io/Portfolio/projects/fintech-aml.html)

### 03. نظام RAG آمن للمؤسسات | بحث في الذكاء الاصطناعي

**Python · NLP · Retrieval-Augmented Generation · LLMs**

بحث وتطوير إطار عمل يعتمد على تقنية التوليد المعزز بالاسترجاع (RAG)، ويعمل دون الحاجة إلى الاتصال بالإنترنت، بهدف دعم استرجاع المعرفة داخل المؤسسات مع مراعاة خصوصية البيانات والقيود التشغيلية.

**أبرز النتائج:**

- دراسة تقنيات استرجاع المستندات محليًا، وإعادة ترتيب النتائج، وتوليد الإجابات باستخدام نماذج اللغة الكبيرة.
- تقييم إعدادات متعددة لعمليات الاسترجاع وتوليد الإجابات.
- تحقيق **متوسط تقييم بلغ 4.29 من 5** خلال التقييم التجريبي.
- دراسة التطبيقات العملية للذكاء الاصطناعي الآمن داخل بيئات الأعمال.

### 04. تحليل مشاعر العملاء من المراجعات

**Python · NLP · Machine Learning · Deep Learning**

تحليل 10,000 مراجعة للعملاء بهدف اكتشاف المشاعر والاتجاهات داخل النصوص غير المنظمة، وتحويل ملاحظات العملاء إلى معلومات تدعم قرارات الأعمال.

**أبرز النتائج:**

- تطبيق تقنيات معالجة اللغة الطبيعية وتجهيز البيانات النصية.
- استكشاف أساليب VADER وTF-IDF لتمثيل النصوص وتحليل المشاعر.
- تقييم نماذج تعلم الآلة التقليدية إلى جانب نماذج تعتمد على LSTM.
- دراسة تحديات تصنيف المشاعر وقياس أداء النماذج المختلفة.

### 05. الاتصالات الدلالية عبر الشبكات المرنة في حالات الكوارث | بحث علمي منشور

**Artificial Intelligence · Computer Vision · Network Simulation**

المشاركة في تأليف بحث علمي يستكشف استخدام الذكاء الاصطناعي والاتصالات الدلالية لتحسين مرونة شبكات الاتصال في حالات الكوارث.

**أبرز النتائج:**

- دراسة نقل المعلومات الدلالية في بيئات الاتصال محدودة الموارد.
- استكشاف الاتصالات المعتمدة على الصور باستخدام تجارب مضبوطة.
- دراسة سلوك الاتصال باستخدام محاكاة لشبكة تتكون من **250 عقدة**.
- المساهمة في بحث قُدّم ضمن **IEEE ITC 2026**.

## نبذة عن موقع معرض الأعمال

هذا الموقع عبارة عن معرض أعمال احترافي متعدد الصفحات، مصمم لعرض خلفيتي المهنية ومشاريعي التحليلية وخبراتي العملية بصورة تفاعلية ومتوافقة مع مختلف الأجهزة.

**أبرز مميزات الموقع:**

- عرض خمس دراسات حالة تفصيلية لمشاريع تحليلية وبحثية.
- تصميم متجاوب مع أجهزة الكمبيوتر والهواتف المحمولة.
- إمكانية تصفية المشاريع وعرض عناصر تفاعلية وحركات بصرية.
- معاينة لوحة معلومات Power BI وإتاحة تحميل عرض تقديمي.
- عرض الخبرات المهنية والمؤهلات التعليمية ووسائل التواصل.
- النشر التلقائي باستخدام GitHub Actions وGitHub Pages.

**التقنيات المستخدمة في تطوير الموقع:**

HTML · CSS · JavaScript · Python · GitHub Actions

### تشغيل الموقع محليًا

أولًا، استنسخ مستودع المشروع باستخدام الأمر التالي:

```bash
git clone https://github.com/Apanoub-Benyamen/Portfolio.git
cd Portfolio
```

ثم شغّل خادمًا محليًا:

```bash
python -m http.server 8000 --directory dist
```

بعد ذلك افتح الرابط التالي في المتصفح:

`http://localhost:8000`

الموقع مبني باستخدام ملفات ثابتة، وتوجد النسخة الجاهزة للنشر داخل مجلد `dist/`.
