### Run Locally

Clone the repository:

```bash
git clone https://github.com/Apanoub-Benyamen/Portfolio.git
cd Portfolio
```

Start a local server:

```bash
python -m http.server 8000 --directory dist
```

Then open `http://localhost:8000` in your browser.

The website is statically generated, and its published files are located in the `dist/` directory.
